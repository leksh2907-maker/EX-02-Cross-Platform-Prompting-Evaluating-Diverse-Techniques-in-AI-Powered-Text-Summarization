# EX-02-Cross-Platform-Prompting-Evaluating-Diverse-Techniques-in-AI-Powered-Text-Summarization

## AIM
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: text summarization.

## Scenario:
You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience

## Algorithm
1.Select the Task Choose Text Summarization as the application and select a technical article on "A Unified Multi-Crop Digital Twin for Explainable AI-Driven Crop Monitoring and Intelligent Farm Management."

2.Choose AI Platforms Select the AI platforms for evaluation:

Google Gemini
copiolt
3.Design Prompt Structures Create prompts using different prompt engineering techniques:

*Basic Prompt
*Role Prompt
*Context Prompt
*Constraint Prompt
*Output Format Prompt
*Final User-Defined Prompt
4.Execute the Prompts Submit each prompt to both AI platforms using the same digital twin/crop monitoring article to ensure a fair comparison.

5.Collect the Outputs Record the summaries generated by Gemini and Grok for each prompt structure.

6.Evaluate the Responses Assess each summary based on: Accuracy, Coherence, Simplicity, Speed, User Experience.

7.Compare the Results Compare the performance of both AI platforms across all prompt structures and identify which platform generates the best summary.

8.Draw the Conclusion Analyze the results and recommend the most effective prompt structure and AI platform for educational text summarization of agri-tech research content.
